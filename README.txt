PW STOCK - GitHub Pages PWA

Files to upload to your GitHub repository:
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

This GitHub app opens your existing Google Apps Script app inside a full-screen installed PWA.
Apps Script backend URL:
https://script.google.com/macros/s/AKfycbxunKvpErIRJmvlZmdzd0OvipNcGxZOSZCP6L06UJPb1IU6r4tNWWdAUNbdlFgiVo/exec

GitHub Pages:
Settings -> Pages -> Deploy from a branch -> main / root -> Save

Then open:
https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/

On Android Chrome:
Menu -> Add to Home screen / Install app

On iPhone Safari:
Share -> Add to Home Screen
